# Security notes

My security notes: web apps, Active Directory, networks, cloud, Kubernetes, mobile, and AI/LLM security.

Read them at **https://gandhi-taha.github.io/security/**

Built with MkDocs and the Material theme. To build locally:

```bash
pip install mkdocs-material
mkdocs serve
```

The site is published from the `gh-pages` branch.
